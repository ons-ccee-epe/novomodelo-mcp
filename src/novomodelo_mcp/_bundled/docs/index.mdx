Novomodelo is an open-source solver for multi-stage stochastic hydrothermal dispatch:
it trains an operating policy with Stochastic Dual Dynamic Programming (SDDP) and
simulates it, from the command line or from Python. This site documents the
method and the software together, from the mathematics and worked examples to
installing Novomodelo, running studies and reading their results.

## Where to start

  - [Run studies](/getting-started/quickstart): Scaffold, validate and run a first study from the command line.
  - [Coming from other software?](/running/case-conversion): Convert an existing case to Novomodelo's input format and compare the results.
  - [Study SDDP](/math/sddp-algorithm): The algorithm chapters: forward and backward passes, cuts, bounds and stopping rules.
  - [Work in Python](/getting-started/python-quickstart): Run a study and read its results from Python.
